# ml-automation-aws

AWS ML platform automation. SageMaker training, S3 data management, Lambda deployment, ECR containers, and AWS ML infrastructure. Requires spark-core installed.

This plugin's work is tracked in Jira project [PM3](https://blend360.atlassian.net/jira/core/projects/PM3/board). Filter the board by label `plugin:aws` for this plugin's slice.
